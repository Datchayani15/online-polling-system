# Online Polling System using Flask

This is a web-based polling application built using the Flask framework. It allows authenticated users to cast votes securely and view real-time poll results. Admin users can create and manage polls through the admin panel.

## Features
- User Registration & Login (Authentication)
- Create and manage polls
- Cast votes securely
- Real-time results display
- Admin dashboard
- Database integration
- Responsive web interface

## Technologies Used
- Python (Flask)
- HTML, CSS, JavaScript (Frontend)
- SQLite / MySQL (Database)
- Bootstrap (UI styling)

## How to Run

### 1. Clone the repository
git clone https://github.com/Datchayani15/online-polling-system-flask.git

### 2. Navigate to the project folder
cd online-polling-system-flask

### 3. Create a virtual environment (recommended)
python -m venv venv

### 4. Activate the virtual environment
# For Windows:
venv\Scripts\activate

# For macOS/Linux:
source venv/bin/activate

### 5. Install dependencies
pip install -r requirements.txt

### 6. Run the application
python app.py

### 7. Open your browser and visit
http://127.0.0.1:5000/
