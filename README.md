# Online Polling System using Flask

This is a web-based polling application built using the Flask framework. It allows authenticated users to cast votes securely and view real-time poll results. Admin users can create and manage polls through the admin panel.

## Features
- User Registration & Login (Authentication)
- Create and manage polls
- Cast votes securely
- Real-time results display
- Admin dashboard
- Database integration
- Responsive web interface

## Technologies Used
- Python (Flask)
- HTML, CSS, JavaScript (Frontend)
- SQLite / MySQL (Database)
- Bootstrap (UI styling)
